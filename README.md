# SnapWake 🌅

A modern, lightweight desktop alarm clock built with Python and Tkinter. Set custom wake-up times, choose from beautiful pre-loaded alarm tones, or browse your own audio files. Features include snooze functionality, persistent alerts, and a sleek dark-mode UI.

**Perfect for:** Developers, students, and anyone who needs a minimal alarm solution that just works.

## Features

- ⏰ **24-hour time format** — Simple, clean time input
- 🎵 **4 preset alarms** — Curated sounds (Classic Clock, Short Alert, Electronic Chime, Bedside Bell)
- 📁 **Custom audio support** — Load any `.mp3`, `.wav`, or `.ogg` file
- 😴 **Smart snooze** — 5-minute default snooze with popup alerts
- 🌙 **Dark UI theme** — Modern, eye-friendly interface
- ⚡ **Lightweight** — Pure Python, minimal dependencies

## Installation

1. Clone or download this repository
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

```bash
python alarm_clock_app.py
```

**Quick start:**
1. Enter alarm time (e.g., `07:30`)
2. Pick a tone from the dropdown or browse custom files
3. Click "Set Alarm"
4. Keep the window open—it monitors the time in background
5. At alarm time, a popup alert with Stop/Snooze appears

## Requirements

- Python 3.10+
- Tkinter (included with Python)
- pygame 2.5.0+
